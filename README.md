## Cómo usar este repo
1. Busca la clase en el índice de abajo (el número coincide con el vídeo).
2. Entra en su carpeta y sigue su `README.md`.
3. Las claves y credenciales van en tu propio `.env` (copia `.env.example`). Nunca las subas a git.

```bash
git clone https://github.com/oscar1223/clases.git
```
